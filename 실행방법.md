# Hellocs MSA 실행 방법

## 서비스 구성

```
hellocs/
├── shared-events/           # Kafka 이벤트 공유 모듈 (라이브러리)
├── core-service/            # 퀴즈, 채점, 사용자, 토픽 (포트 8080)
└── ranking-streak-service/  # 랭킹, 스트릭 (포트 8081)
```

### 데이터베이스 구성

| 서비스 | DB |
|--------|-----|
| core-service | PostgreSQL (퀴즈/사용자/채점), MongoDB (채점 로그) |
| ranking-streak-service | Redis (랭킹), MongoDB (스트릭) |

### 서비스 간 통신

- **이벤트**: 채점 완료 시 core-service → Kafka(`grading.completed`) → ranking-streak-service
- **HTTP**: ranking-streak-service → core-service `/internal/v1/users/**`, `/internal/v1/topics/**` (사용자/토픽 조회)

## 방법 1 — 로컬 개발 (IDE + 인프라만 Docker)

> 코드를 수정하면서 빠르게 실행할 때 사용합니다.

### 1단계: 인프라 실행

```bash
docker compose -f docker-compose.local.yml up -d
```

아래 인프라가 localhost에 올라옵니다.

| 서비스 | 포트 |
|--------|------|
| PostgreSQL | 5432 |
| Redis | 6379 |
| MongoDB | 27017 |
| Kafka | 9092 |
| Zookeeper | 2181 |

인프라 상태 확인:

```bash
docker compose -f docker-compose.local.yml ps
```

### 2단계: core-service 실행

```bash
./gradlew :core-service:bootRun --args='--spring.profiles.active=dev'
```

- 포트: `8080` (API), `8081` (Actuator)
- Swagger UI: http://localhost:8080/swagger-ui/index.html

### 3단계: ranking-streak-service 실행 (새 터미널)

```bash
./gradlew :ranking-streak-service:bootRun --args='--spring.profiles.active=dev'
```

- 포트: `8081` (API), `8082` (Actuator)

### 인프라 종료

```bash
docker compose -f docker-compose.local.yml down
```

데이터 볼륨까지 삭제하려면:

```bash
docker compose -f docker-compose.local.yml down -v
```

## 방법 2 — 전체 스택 Docker (운영/배포 환경)

> 두 서비스 모두 컨테이너로 실행합니다.

### 사전 준비: 환경 변수 파일 생성

프로젝트 루트에 `.env` 파일을 만들어 주세요.

```dotenv
# PostgreSQL
POSTGRES_DB=hellocs
POSTGRES_USER=hellocs
POSTGRES_PASSWORD=your-postgres-password

# Redis
REDIS_PASSWORD=your-redis-password
REDIS_TIMEOUT=3s

# MongoDB
MONGO_INITDB_ROOT_USERNAME=hellocs
MONGO_INITDB_ROOT_PASSWORD=your-mongo-password
MONGO_DB=hellocs
MONGO_URI=mongodb://hellocs:your-mongo-password@mongo:27017/hellocs?authSource=admin

# JWT
JWT_SECRET=your-base64-encoded-secret
JWT_ACCESS_TOKEN_EXPIRATION=3600000
JWT_REFRESH_TOKEN_EXPIRATION=360000000

# Kakao OAuth
KAKAO_CLIENT_ID=your-kakao-client-id
KAKAO_CLIENT_SECRET=your-kakao-client-secret
KAKAO_REDIRECT_URI=https://your-domain.com/api/v1/auth/token

# AI 서버
AI_GRADING_EVALUATE_ENDPOINT=http://your-ai-server/api/feedback/evaluate
AI_STT_TRANSCRIBE_ENDPOINT=http://your-ai-server/api/transcribe

# JVM
JAVA_OPTS=-Xms256m -Xmx768m

# Grafana
GRAFANA_ADMIN_USER=admin
GRAFANA_ADMIN_PASSWORD=your-grafana-password
GRAFANA_ROOT_URL=https://your-domain.com/grafana
```

### 빌드 및 실행

```bash
# 이미지 빌드 + 전체 스택 실행 (처음 또는 코드 변경 시)
docker compose up -d --build

# 이미지가 이미 있을 때 (빠른 재시작)
docker compose up -d
```

### 서비스 포트 (컨테이너 내부)

| 서비스 | 포트 |
|--------|------|
| core-service API | 8080 |
| core-service Actuator | 8081 |
| ranking-streak-service API | 8081 |
| ranking-streak-service Actuator | 8082 |
| nginx (외부 노출) | 80, 443 |

### 로그 확인

```bash
# core-service 로그 실시간 확인
docker compose logs -f core-service

# ranking-streak-service 로그 확인
docker compose logs -f ranking-streak-service

# Kafka 로그 확인
docker compose logs -f kafka
```

### 헬스 체크

```bash
# core-service
curl http://localhost:8081/actuator/health

# ranking-streak-service (호스트에서 직접 접근 시 포트 노출 필요)
docker compose exec ranking-streak-service curl http://localhost:8082/actuator/health
```

### 전체 종료

```bash
docker compose down
```

## 방법 3 — 테스트 실행

### 전체 테스트

```bash
./gradlew test
```

### 서비스별 테스트

```bash
# core-service 테스트만
./gradlew :core-service:test

# ranking-streak-service 테스트만
./gradlew :ranking-streak-service:test
```

### 특정 테스트 클래스 실행

```bash
# 채점 서비스 Kafka 발행 테스트
./gradlew :core-service:test --tests "com.deadlock.hellocs.quiz.grading.application.service.GradingCommandServiceTest"

# 랭킹 서비스 테스트
./gradlew :ranking-streak-service:test --tests "com.deadlock.hellocs.ranking.application.service.RankingServiceTest"
```

## 트러블슈팅

### Kafka 연결 실패

```bash
# Kafka 토픽 목록 확인
docker compose -f docker-compose.local.yml exec kafka kafka-topics --bootstrap-server localhost:9092 --list

# grading.completed 토픽 메시지 실시간 확인
docker compose -f docker-compose.local.yml exec kafka kafka-console-consumer \
  --bootstrap-server localhost:9092 \
  --topic grading.completed \
  --from-beginning
```

### Dead Letter Topic 확인 (소비 실패한 메시지)

```bash
docker compose exec kafka kafka-console-consumer \
  --bootstrap-server kafka:9092 \
  --topic grading.completed.DLT \
  --from-beginning
```

### PostgreSQL 접속

```bash
# 로컬 개발 환경
docker compose -f docker-compose.local.yml exec postgres psql -U postgres -d postgres
```

### MongoDB 접속

```bash
# 로컬 개발 환경
docker compose -f docker-compose.local.yml exec mongo mongosh
```

### Redis 접속

```bash
# 로컬 개발 환경
docker compose -f docker-compose.local.yml exec redis redis-cli
```
